# Supplementary Movies for GNSS-Derived dTEC TID-Like Candidate Screening

This repository provides public access to supplementary movies associated with the manuscript:

**Auditable Screening of TID-Like Ionospheric Disturbance Candidates From GNSS-Derived dTEC Map Sequences**

Validation case: VNDP, 2019-06-12 UTC.

## Release assets

- 	id_dtec_screening_video1.mp4: Supplementary Movie S1, primary expert-audited TID-like candidate, Event 14.
- 	id_dtec_screening_video2.mp4: Supplementary Movie S2, supporting moderate TID-like candidates, Events 6, 10, 12, and 18.
- 	id_dtec_screening_video3.mp4: Supplementary Movie S3, artifact/ambiguous ablation examples, Events 20, 22, and 24.

The labels are expert-audited weak labels and are not independently confirmed ground-truth TID events.
